# Структура публичных страниц Epifera

Дата: 23 октября 2026 года. Статус: проект структуры для наполнения и будущей реализации.

[Основной документ](../../superpowers/specs/2026-10-23-epifera-seo-structure-design.md) описывает 24 семейства шаблонов, их блоки, данные, связи, источники фактов, правила публикации и этапы наполнения.

[catalog.json](catalog.json) содержит:

- `templates` — 24 шаблона с путями, блоками, обязательными полями и условиями публикации;
- `entities` — 25 типов записей, включая редакционное содержание, маршруты, таксономию, свидетельства, публичные медиа и безопасные действия;
- `commonEditorialFields`, `localizedFields`, `storageContract` — общие поля, переводы и правила размещения данных;
- `publicationGates` — общие и специфические условия;
- `pilotPages` — 60 кандидатов для очереди наполнения, с источниками и недостающими данными;
- `mediaVariants` — параметры карточек разных типов материалов;
- `validationRules` — проверки связей, маршрутов, источников и приватности.

Кандидаты не являются готовым выпуском. У всех `indexEligible=false`; это свойство проектной очереди, которое не меняет действующий sitemap главной. Только главная имеет существующий публичный маршрут. Упоминание интерфейса `/app/*` не подтверждает доступность конкретной модели или операции. Примеры кейса, события, публичного результата и стокового файла прямо помечены как иллюстративные.

Каталог не импортируется приложением. Он не содержит реальных пользовательских промптов, приватных файлов, цен, учётных записей или провайдерских ключей. Поля `source` задают ожидаемого владельца данных, а не утверждают, что все данные уже получены. Типы полей логические; это не текущая Zod схема и не исполняемая JSON Schema.

Проект сохраняет действующие `/ru` и `/en`, русский язык по умолчанию и прежние границы серверной доступности моделей. Английский Magnific используется как карта охвата; основной язык Epifera этим не назначается. Его [реестр](../magnific-seo-registry/README.md) остаётся исходным исследованием, а предложенные здесь пути уточняют будущую структуру Epifera.
