# Shared Inspiration Examples Implementation Plan

**Goal:** Заменить заглушки во вкладке «Примеры генераций» реальными интерактивными карточками из «Вдохновения» без дублирования данных и поведения.

**Architecture:** Типизированный каталог хранит метаданные примеров. Один компонент `InspirationExampleCard` рендерит карточку и модальное окно во всех местах. `InspirationGallery` показывает полный каталог, а `ImageGenerationGuide` запрашивает небольшую подборку для выбранной модели и использует общую подборку как fallback.

**Tech Stack:** TypeScript, React 19, Next.js 16, CSS Modules, Vitest, Testing Library.

## Constraints

- Бэкенд и API не изменяются.
- Промпт, изображение, модель и параметры не дублируются между экранами.
- Модальное окно сохраняет текущие действия: копирование, пересоздание, скачивание и отправку ссылки.
- Если для выбранной модели ещё нет примера, вкладка показывает общую подборку вместо пустого состояния.
