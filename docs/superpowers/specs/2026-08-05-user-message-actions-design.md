# Действия под сообщением пользователя

## Цель

Под каждым сообщением пользователя в обычном чате показать две компактные иконки: «Копировать» и «Пересоздать».

## Согласованное поведение

- «Копировать» записывает полный текст выбранного сообщения в буфер обмена.
- «Пересоздать» заменяет текущий черновик в поле ввода полным текстом выбранного сообщения.
- После «Пересоздать» запрос не отправляется автоматически.
- Фокус и позиция прокрутки не меняются.
- Действия доступны только у сообщений пользователя, включая оптимистично показанное сообщение во время ожидания ответа.

## Архитектура

`ConversationMessageActions` отвечает только за две кнопки, копирование и вызов `onRecreate(text)`. `ConversationHistory` хранит одноразовый запрос на замену черновика с монотонным идентификатором и передаёт его в `ConversationComposer`. Композер реагирует на новый идентификатор и обновляет только своё состояние `draft`, не вызывая `focus()` или прокрутку.

Такой контракт выбран вместо императивного `ref` и глобального события: он остаётся типизированным, локальным для конкретного чата и легко проверяется интеграционным тестом.

## Внешний вид и доступность

Кнопки располагаются горизонтально под текстом внутри пользовательской карточки. Они имеют небольшой квадратный размер, прозрачный фон, нейтральный цвет и состояния hover/focus. Видимый текст не добавляется; назначение задаётся через `aria-label` и `title`.

## Проверка

- Копирование передаёт в Clipboard API точный текст сообщения.
- Пересоздание заменяет существующий черновик точным текстом сообщения.
- После пересоздания поле ввода не получает фокус.
- У сообщений NeiroHub кнопки отсутствуют.
