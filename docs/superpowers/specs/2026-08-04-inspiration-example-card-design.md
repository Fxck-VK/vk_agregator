# Пример интерактивной карточки «Вдохновения»

## Цель

Заменить заглушку раздела «Вдохновение» одной полноценной примерной карточкой. По нажатию карточка открывает полноэкранный просмотр, аналогичный предоставленному референсу, но с собственным изображением и визуальным языком NeiroHub.

## Компоненты

- `InspirationGallery` владеет данными публичного примера и состоянием выбранной карточки.
- `InspirationCard` показывает локальное изображение, название модели и действие «Подробнее».
- `InspirationDetail` показывает полноэкранный dialog: миниатюру слева, крупное изображение, информацию и действия справа.
- `WorkspaceHome` делегирует раздел `inspiration` новому компоненту; остальные разделы не меняются.

## Данные примера

- Локальное оригинальное изображение: бумажный журавль на облаке в тёплой комнате.
- Модель: `GPT Image 2`.
- Качество: `1K`.
- Промпт хранится в клиентском публичном объекте примера.
- Backend и персональные данные не используются.

## Взаимодействия

- Карточка открывается кликом или клавиатурой.
- Dialog закрывается крестиком, `Escape` и кликом по затемнённому фону; фокус возвращается на карточку.
- «Копировать» отправляет промпт в Clipboard API и показывает нейтральный статус.
- «Пересоздать» открывает `/app/image` с `model`, `quality` и `prompt` в query string; пользователь подтверждает актуальную цену уже в генераторе.
- «Скачать» использует ссылку на локальный asset с атрибутом `download`.
- «Поделиться» использует Web Share API, а при его отсутствии копирует текущую ссылку.

## Адаптивность и доступность

- На широком экране dialog состоит из трёх зон: миниатюры, изображение, панель информации.
- На узком экране зоны становятся одной колонкой, панель действий остаётся доступной обычной прокруткой.
- Dialog имеет имя, `aria-modal`, заметный фокус и блокирует прокрутку страницы на время открытия.
- Изображение имеет содержательный alt, кнопки имеют текстовые доступные имена.

## Проверка

- Компонентные тесты покрывают открытие, закрытие, возврат фокуса, копирование промпта и параметры ссылки «Пересоздать».
- Стилевой тест фиксирует полноэкранный overlay и мобильную перестройку.
- Полный test/typecheck/lint/build веб-платформы остаётся зелёным.

## Границы

В этом срезе создаётся ровно одна карточка. Нет серверного каталога вдохновения, пагинации, лайков, реального тарифа, автоматического запуска генерации и дополнительных карточек.
