# Количество изображений за один запрос

## Цель

Добавить в универсальный генератор изображений компактный счётчик `− 1 / 4 +`. Пользователь выбирает от одного до максимально разрешённого моделью количества изображений, сразу видит полную стоимость и отправляет один идемпотентный запрос.

## Правила

- Значение по умолчанию — `1`.
- Максимум приходит из серверного каталога модели (`max_output_count`), а не зашивается только во frontend.
- Стоимость равна серверной цене одного изображения, умноженной на выбранное количество.
- Сервер повторно проверяет диапазон и рассчитывает итоговую цену; frontend не является источником истины.
- Количество входит в параметры идемпотентного запроса и worker payload.
- Провайдер получает количество через его нативное поле `n`, если модель это поддерживает.
- При смене модели выбранное количество ограничивается новым максимумом.
- Старые клиенты без `output_count` продолжают создавать одно изображение.

## UI

Счётчик является отдельным независимым React-компонентом. Кнопки `−` и `+` имеют доступные подписи, отключаются на границах и не допускают некорректного значения. Компонент подключается к общему image composer рядом с соотношением сторон и качеством.

## Надёжность

- Сервер отклоняет отрицательные значения и значения выше лимита модели.
- Нулевое/отсутствующее значение нормализуется в `1` для обратной совместимости.
- Переполнение при умножении цены приводит к безопасной ошибке расчёта.
- Подготовленный job сохраняет выбранное количество, чтобы повтор idempotency key нельзя было использовать с другими параметрами.
