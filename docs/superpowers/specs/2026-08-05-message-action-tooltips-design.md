# Единые подсказки действий под сообщениями

## Цель

Привести кнопки «Копировать сообщение», «Пересоздать сообщение», «Лайк» и «Дизлайк» к одному визуальному поведению: фирменная подсказка NeiroHub появляется под кнопкой при наведении мыши или клавиатурном фокусе.

## Границы изменения

- Меняется только компонент действий под сообщением и его CSS-модуль.
- Расположение кнопок, иконки и существующая логика нажатий не меняются.
- Состояние «Скопировано» и двухсекундный таймер сохраняются.
- Backend, API и модель данных не меняются.

## Рассмотренные подходы

1. **Общий CSS-псевдоэлемент для кнопок с `data-tooltip` — выбран.** Минимальная разметка, единый стиль и отсутствие дополнительного React-состояния для показа подсказки.
2. Отдельный React-компонент с порталом. Лучше решает сложные столкновения с краями экрана, но для четырёх компактных кнопок добавляет лишнюю сложность.
3. Нативный атрибут `title`. Не позволяет управлять стилем и расположением, поэтому не соответствует макету.

## Поведение и внешний вид

- Каждая кнопка получает локализованный `data-tooltip`, совпадающий с её `aria-label`.
- Нативный `title` удаляется, чтобы браузерная подсказка не конкурировала с интерфейсом NeiroHub.
- Общий псевдоэлемент привязывается к `.action[data-tooltip]`.
- Подсказка располагается по центру под кнопкой через `inset-block-start: calc(100% + var(--space-2))`.
- Используются существующие токены фона, границы, текста, скругления, тени и анимации NeiroHub.
- Подсказка появляется на `hover` и `focus-visible`, не перехватывает события указателя и находится поверх соседнего содержимого.

## Проверка

- DOM-тест подтверждает `data-tooltip` и отсутствие `title` у всех четырёх действий.
- CSS-контракт подтверждает общий селектор и позиционирование подсказки снизу.
- Существующие тесты отдельно подтверждают копирование, взаимоисключающий лайк/дизлайк и перенос текста в поле при пересоздании.
