# Масштабирование 24 публичных шаблонов

Статус: реализация согласованного владельцем решения от 29.10.2026.

## Контракт

Существующая вёрстка и взаимодействия сохраняются. Каталог русских страниц содержит стабильный ID, тип T01–T24, канонический адрес без локали, SEO, статус, даты, связанные ID и данные именованных источников шаблона. Данные не содержат JSX, HTML, функций или секретов. Один шаблон обслуживает все свои записи. Общие части переиспользуются только при совпадении существующего оформления.

Именованные источники проходят проверку по структуре действующего шаблона. Привязка источника явная; подмена строк по совпадению текста и изменение DOM запрещены. Производные данные вычисляются из выбранной записи. Старые адреса используют тот же рендерер, новые разрешаются существующим catch-all без перехвата кабинета, API, входа и статических служебных маршрутов. Неизвестный адрес сохраняет HTTP 404. Черновики доступны для локальной проверки; на сервере новые неопубликованные записи не раскрываются.

T18 сохраняет серверную экономику, T23 — проверенный runtime-каталог юридических документов; редакционный каталог не может подменять суммы, условия платежей или юридические тексты. Главная и тарифы остаются единичными каноническими страницами. Уроки и статьи справки сохраняют существующие вложенные маршруты.

Публикация и sitemap имеют один источник статуса. В карту попадают только published/index записи с наступившей датой. Валидация выявляет неизвестный тип/источник, недостающие поля, несовместимые блоки, повторяющиеся ID/адреса, некорректные ссылки, медиа и даты, а также конфликт с существующими маршрутами. Только ru; /en остаётся перенаправлением.

## Проверка

Регрессионные тесты всех 24 адаптеров, двух разных записей одного типа, обновления общих компонентов, источников дочерних блоков, изоляции записей, публикации/архива/даты, robots/canonical/sitemap, 404/служебных маршрутов. Проверки типов, линтер, язык, публикации, сборка и локальный HTTP. Без commit/push/deploy.
