# Единые боковые отступы страниц workspace

## Цель

Выровнять содержимое страниц «Главная», «Мои файлы», «Нейросети» и «Вдохновение» по одним вертикальным направляющим, отмеченным пользователем красными линиями.

## Дизайн

- Существующая центральная колонка главной страницы шириной `46rem` остаётся источником истины.
- Глобальные токены задают максимальную ширину содержимого и адаптивный боковой отступ.
- Общий компонент `WorkspacePageFrame` повторяет двухуровневую геометрию главной: внешний центрированный контейнер `66rem` с адаптивным gutter и внутреннюю колонку `46rem`.
- В диапазоне `48rem–82rem` компонент сохраняет существующий сдвиг главной вправо, чтобы содержимое не пересекалось с плавающим селектором модели.
- «Мои файлы», «Нейросети» и «Вдохновение» используют этот компонент вместо собственных значений `78rem`, `64rem` и `90rem`.
- На экранах уже `48rem` боковой отступ равен `1rem`.
- Полноэкранные рабочие области чата и генерации изображений не меняются.

## Проверка

CSS-контракт проверяет глобальные токены, геометрию общего компонента и использование компонента тремя страницами. Дополнительно запускаются тесты затронутых компонентов, TypeScript, ESLint и визуальная проверка локального приложения.
