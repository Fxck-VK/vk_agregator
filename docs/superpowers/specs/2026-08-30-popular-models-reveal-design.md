# Раскрытие популярных моделей

## Цель

Сделать блок «Популярные нейросети» компактным: сначала показывать четыре карточки, затем по кнопке «Показать ещё» раскрывать не более двух следующих карточек каталога. После раскрытия под сеткой должна появляться кнопка «Все нейросети» с переходом на `/app/models`.

## Поведение

- Верхняя кнопка «Все нейросети» рядом с заголовком удаляется.
- Каталог загружается один раз, как и сейчас.
- До раскрытия видны первые четыре модели.
- Если каталог содержит больше четырёх моделей, под первой сеткой по центру показывается «Показать ещё».
- Нажатие не перезагружает страницу, скрывает «Показать ещё» и показывает максимум две следующие модели.
- После раскрытия под карточками появляется «Все нейросети» с переходом на `/app/models`.
- Если каталог содержит не больше четырёх моделей, «Показать ещё» не показывается, а ссылка «Все нейросети» доступна сразу.
- На узких экранах существующая одноколоночная сетка сохраняется.

## Архитектура

Интерактивность остаётся внутри клиентского компонента `FeaturedModels`: он уже загружает каталог и управляет состоянием. `WorkspaceLanding` отвечает только за заголовок секции. Оба действия используют одну декоративную кнопку с уже подключённым PNG-фоном.

## Доступность и проверка

«Показать ещё» — настоящая кнопка с `aria-expanded` и `aria-controls`. Финальное действие — ссылка. Компонентный тест проверяет начальные четыре карточки, раскрытие ещё двух, исчезновение первой кнопки и появление ссылки на каталог.
