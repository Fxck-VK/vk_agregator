# Видео «Как работает NeiroHub»

## Цель

Заменить заглушку в секции «Как работает NeiroHub» на предоставленный пользователем файл `videoplayback.mp4`, не меняя размеры, рамку и скругление существующей карточки.

## Поведение

- Видео показывается внутри существующего компонента `VideoPlayer` и заполняет весь его контейнер 16:9 с `object-fit: contain`.
- До первого запуска видео закрыто фирменной тёмной градиентной заставкой с одной круглой кнопкой Play по центру и без текста.
- Нижние стандартные элементы управления браузера скрыты под заставкой и становятся доступны после первого запуска.
- Нажатие на центральную кнопку скрывает заставку и запускает видео; при дальнейшей паузе заставка не возвращается.
- Автоматическое воспроизведение отключено.
- Предварительная загрузка отключена через `preload="none"`, чтобы файл размером около 7,8 МБ не загружался до действия пользователя.
- При ошибке воспроизведения компонент показывает существующее сообщение «Видео временно недоступно».
- Постер не добавляется: до запуска браузер показывает первый доступный кадр или нейтральный фон видеоплеера.

## Ассеты

Файл хранится по стабильному пути `public/assets/videos/workspace/neirohub-how-it-works.mp4`. Путь экспортируется как `assetPaths.videos.workspace.howItWorks`. Валидатор ассетов расширяется поддержкой файлов `.mp4` с именами в kebab-case.

## Проверка

Компонентный тест подтверждает наличие доступной кнопки запуска без текста-заглушки, отсутствие native controls до клика, вызов `play()` и появление controls после клика. Тест главной страницы подтверждает локальный MP4-источник и `preload="none"`. После автоматических проверок заставка и запуск видео проверяются на локальной странице `http://localhost:7158/app`.
