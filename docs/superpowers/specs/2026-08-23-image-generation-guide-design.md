# Image Generation Guide Design

## Goal

Добавить под универсальным инпутом генерации изображений компактный обучающий блок в стилистике NeiroHub, повторяющий структуру согласованных референсов без копирования чужих изображений.

## Layout

- Блок располагается между `ImageGenerationPanel` и историей генераций.
- Вверху находятся вкладки «Как использовать» и «Примеры генераций».
- «Как использовать» показывает три карточки в один ряд на десктопе и колонкой на мобильном:
  1. пример подробного промпта;
  2. пример настройки генерации с декоративными контролами «Загрузить медиа» и «2:3»;
  3. многослойную заглушку готового результата.
- Под каждой карточкой показываются номер шага, заголовок и краткое описание.
- «Примеры генераций» показывает три нейтральные заглушки будущей галереи.

## Architecture

- Новый независимый компонент `ImageGenerationGuide` отвечает только за вкладки и обучающий контент.
- Все пользовательские строки добавляются в `ru.imageGeneration.guide`.
- Иллюстрации пока создаются CSS-заглушками; сетевых запросов и изменений бэкенда нет.
- `ImageWorkspace` только размещает компонент в правильном порядке.

## Interaction and accessibility

- Вкладки реализуются через `role="tablist"`, `role="tab"` и `role="tabpanel"`.
- Активная вкладка имеет `aria-selected="true"` и видимое подчёркивание.
- Декоративные контролы внутри обучающих карточек не объявляются кнопками.
- На ширине до 760px карточки переходят в одну колонку.
