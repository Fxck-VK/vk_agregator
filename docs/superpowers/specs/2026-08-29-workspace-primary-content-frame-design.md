# Единые боковые отступы основных блоков workspace

## Цель

Выровнять по одним вертикальным границам поле ввода, ряд быстрых моделей и секцию «Популярные нейросети», создав симметричные внешние отступы, отмеченные пользователем красными линиями.

## Утверждённый вариант

- Hero-секция целиком — заголовок, описание, поле ввода и ряд быстрых моделей — помещается в центрированный контейнер шириной не более `50rem`.
- Секция «Популярные нейросети» — заголовок, описание, кнопка и карточки — использует тот же контейнер `50rem`.
- Контейнер занимает `100%` доступной ширины на узких экранах и центрируется через `margin-inline: auto`.
- Общий контейнер страницы `.main`, его padding, внутренние отступы компонентов, размеры элементов, боковая панель и остальные нижние секции не меняются.

## Архитектура

В `WorkspaceLanding.module.css` добавляется общий класс `.contentFrame`. В `WorkspaceLanding.tsx` этот класс применяется ровно к hero и к секции популярных моделей. Отдельные значения ширины в дочерних компонентах не добавляются.

## Проверка

- CSS-контракт подтверждает `inline-size: min(100%, 50rem)` и `margin-inline: auto`.
- Контракт разметки подтверждает применение `contentFrame` ровно к двум нужным секциям.
- Полные тесты, lint, typecheck, production build и packaging должны завершиться без ошибок.

## Доставка

Изменение коммитится локально. Push выполняется только по отдельной команде пользователя.
