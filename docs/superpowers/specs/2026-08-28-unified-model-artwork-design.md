# Единая базовая заставка моделей

## Цель

Во всех интерфейсах выбора и показа нейросетей использовать одну базовую заставку с улыбающимся значком из `public/assets/images/models/default-model-87465de8.png`. Не допускать серого значка сломанного изображения.

## Текущее расхождение

- `ModelCard` и `FeaturedModelShortcuts` используют `ModelIcon` с PNG из `public`.
- `WorkspaceModelSelector` отдельно рисует символ `✦` и не использует `ModelIcon`.
- При ошибке загрузки `ModelIcon` оставляет браузерный индикатор сломанного изображения.

## Рассмотренные варианты

1. Оставить отдельные реализации и только заменить символ в селекторе. Это сохраняет дублирование и риск нового расхождения.
2. Полностью заменить PNG на CSS-символ. Это надёжно, но не соответствует выбранной пользователем базовой заставке.
3. Использовать общий `ModelIcon` во всех трёх местах и добавить встроенный визуальный fallback. Это выбранный вариант: единый источник оформления, минимальный объём изменений и отсутствие битого изображения.

## Дизайн

- `ModelIcon` остаётся единственной точкой отображения заставки модели.
- По умолчанию он загружает существующий базовый PNG прямым публичным URL без оптимизатора Next.js.
- Если переданное или базовое изображение не загружается, компонент скрывает сломанный `<img>` и показывает визуально согласованный встроенный fallback.
- `WorkspaceModelSelector` использует `ModelIcon` и для кнопки, и для строк списка.
- `ModelCard` и `FeaturedModelShortcuts` продолжают использовать тот же компонент.
- Размеры, отступы, карточки, скругления и данные моделей не меняются.

## Проверка

- Компонентный тест подтверждает базовый источник, прямую загрузку и fallback после `error`.
- Тест селектора подтверждает использование общего `ModelIcon` вместо символа `✦`.
- Существующие тесты каталога и главной страницы должны остаться зелёными.
- После реализации выполняются целевые тесты, полный тестовый набор платформы, lint, typecheck и production build.
