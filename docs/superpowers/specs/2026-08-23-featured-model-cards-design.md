# Компактные карточки нейросетей на главной

## Цель

Заменить в `/app` четыре крупные абстрактные карточки сценариев на компактный блок конкретных нейросетей. Блок должен выглядеть как часть продукта, а не как универсальный SaaS-шаблон, и не должен показывать выдуманные рейтинги, число пользователей или устаревающие цены.

## Решение

- Заголовок блока: «Популярные нейросети»; подзаголовок коротко объясняет, что это модели для изображений.
- Карточки загружаются из существующего безопасного каталога моделей и используют его как единственный источник названия, возможностей, вариантов качества и цены.
- Показываются первые четыре модели каталога. Вся карточка ведёт в генератор с выбранной моделью.
- В правом верхнем углу выводится минимальная серверная цена в звёздах, если она присутствует в DTO.
- Внизу выводятся только подтверждённые DTO-факты: варианты качества и наличие поддержки референса.
- До загрузки отображаются четыре нейтральные skeleton-карточки без текста «Загружаем…».
- Реальные иконки пока не добавляются. Для них используется нейтральный пустой слот с устойчивым размером, который позднее можно заменить без изменения разметки карточки.
- Удаляются цветные буквенные плитки `NH / IMG / AI / IDEA`, повторяющиеся ссылки «Открыть →», крупный маркетинговый kicker и лишняя высота карточек.

## Границы

- Верхняя лента быстрых действий остаётся без изменений.
- Экран «Все нейросети» и API каталога не меняются.
- Рейтинг и число запусков не показываются, пока сервер не начнёт возвращать эти данные.
- Остальные секции `/app` не меняются.

## Проверка

- Интеграционный тест главной проверяет новый заголовок и отсутствие старой копии.
- Компонентный тест проверяет четыре карточки, серверную цену, подтверждённые характеристики, ссылки на выбранную модель и отсутствие выдуманных метрик.
- TypeScript, ESLint и целевые Vitest-тесты должны проходить.
