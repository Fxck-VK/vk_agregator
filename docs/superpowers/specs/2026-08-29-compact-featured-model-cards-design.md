# Компактные карточки популярных моделей

## Цель

Упростить карточки блока «Популярные нейросети»: оставить иконку, цену, название и короткое тематическое описание, уменьшив визуальную ширину и высоту карточек.

## Утверждённый вариант

- Цена показывается без слова «от»: `50 ✦`, `40 ✦`, `30 ✦`.
- Нижние плашки с разрешениями и поддержкой референсов полностью удаляются из этого блока.
- Каждая из четырёх доступных моделей получает собственное описание:
  - Nano Banana 2 — «Быстрая генерация и редактирование изображений для повседневных задач».
  - Nano Banana Pro — «Детализированные изображения для сложных творческих и рабочих задач».
  - GPT Image 2 — «Точное создание изображений по описанию с хорошей передачей текста».
  - Seedream 4.5 — «Фотореалистичные изображения с высокой детализацией и выразительным стилем».
- Для неизвестной модели используется нейтральное описание с её названием, без предположений о неподтверждённых возможностях.
- Десктопная сетка сохраняет две колонки, ограничивается шириной `58rem` и центрируется.
- Минимальная высота карточки уменьшается с `14.5rem` до `11.5rem`; внутренний разрыв уменьшается до `var(--space-3)`.
- На мобильном экране остаётся одна колонка без отдельной повышенной минимальной высоты.

## Границы изменения

Меняются только `FeaturedModels`, его CSS и связанные тесты. Каталог моделей, селектор, генератор изображений, цены API, размеры иконок, цвета, рамки, скругления и другие карточки платформы не изменяются.

## Проверка

- Компонентный тест подтверждает цену без «от», четыре тематических описания и отсутствие обеих нижних плашек.
- CSS-контракт подтверждает максимальную ширину сетки `58rem`, центрирование и минимальную высоту карточки `11.5rem`.
- Полные тесты, lint, typecheck, production build и packaging должны завершиться без ошибок.
- Результат проверяется локально в браузере на десктопной и мобильной ширине.

## Доставка

Изменение коммитится локально. Push выполняется только по отдельной команде пользователя.
