# Тематические базовые иконки модели

## Цель

Использовать присланный пользователем `chip_silhouette.svg` как светлую базовую иконку-заглушку в тёмной теме, а `chip_silhouette_dark.svg` — как тёмную базовую иконку-заглушку в светлой теме. Обе относятся к одному общему компоненту и применяются только к нейросетям, у которых ещё нет собственной картинки.

## Область изменения

Базовая иконка применяется во всех потребителях `ModelIcon`, когда параметр `src` отсутствует:

- карточки каталога нейросетей;
- селектор нейросети и его список;
- блок популярных нейросетей.

Логотип NeiroHub, навигационные и остальные интерфейсные иконки не меняются. Индивидуальная картинка модели, переданная через `src`, имеет приоритет над базовой заглушкой.

## Рассмотренные варианты

1. Скопировать SVG в `public` и показывать его обычным `<img>`. Это использует точный файл, но при ошибке загрузки браузер снова может показать системный значок битого изображения.
2. Перенести геометрию SVG в JSX. Это убирает сетевую загрузку, но создаёт отдельную кодовую копию рисунка и повторяет ошибку с самостоятельно встроенной иконкой.
3. Скопировать SVG без изменения в `public` и использовать его как фоновое изображение контейнера базовой иконки. Это выбранный вариант: отображается точный пользовательский файл, в разметке нет `<img>` для заглушки, а значит системный значок битого изображения не появляется.

## Архитектура

- Исходный файл `D:/Downloads/chip_silhouette.svg` копируется без изменения содержимого в `web/platform/public/assets/images/models/chip-silhouette.svg`.
- Присланная пользователем SVG-разметка светлой темы сохраняется в `web/platform/public/assets/images/models/chip-silhouette-dark.svg` с исходной геометрией маски и цветом `#15161C`.
- `assetPaths.images.models.fallback` содержит отдельные стабильные пути `darkTheme` и `lightTheme`.
- `DefaultModelArtwork` остаётся единственным общим компонентом заглушки и передаёт оба пути через CSS-переменные.
- CSS выбирает белую иконку для тёмной темы, тёмную — для явной светлой темы и системной светлой темы. Отслеживание темы в React не добавляется.
- При отсутствии `src` `ModelIcon` сразу показывает эту заглушку.
- При ошибке индивидуальной картинки `ModelIcon` переключается на ту же заглушку.
- Старый PNG остаётся в репозитории, если он используется историей или внешними ссылками, но базовый интерфейс на него больше не ссылается.

## Визуальные ограничения

- Содержимое `chip_silhouette.svg` для тёмной темы не редактируется.
- Для светлой темы сохраняются присланные пользователем `viewBox`, маска `face-cutout`, координаты контактов и лица, цвет `#15161C` и прозрачный фон.
- Размеры иконки, внешние и внутренние отступы, рамки, скругления, размеры карточек и остальной дизайн не меняются.

## Проверка

- Тест подтверждает, что заглушка получает оба тематических пути и не содержит самостоятельно нарисованный inline SVG.
- CSS-контракт подтверждает выбор белой иконки в тёмной теме и тёмной иконки в явной или системной светлой теме.
- Тест подтверждает, что индивидуальная картинка модели по-прежнему отображается.
- Тест подтверждает переход ошибочной индивидуальной картинки на базовую заглушку.
- Контрактный тест проверяет маску, ключевую геометрию и цвет присланного SVG светлой темы; неизменность исходного файла тёмной темы проверяется отдельно.
- Запускаются тесты потребителей `ModelIcon`, полный Vitest-набор, asset validation, lint, typecheck, production build и packaging.

## Доставка

Изменение коммитится локально. Пуш выполняется только по отдельной команде пользователя.
