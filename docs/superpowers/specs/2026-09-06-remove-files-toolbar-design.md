# Удаление панели фильтров в «Моих файлах»

## Цель

Убрать со страницы «Мои файлы» весь блок над карточками: подписи поиска и статуса, поле поиска, выбор статуса и пояснение о фильтрации загруженных результатов.

## Поведение

- После вкладок сразу отображается состояние загрузки, пустое состояние, ошибка или сетка карточек.
- Все уже загруженные задания показываются без локальной фильтрации по тексту и статусу.
- Переключение вкладок, загрузка первой страницы, дозагрузка по курсору, получение превью и повторные запуски не меняются.
- Компонент `FilesToolbar` не удаляется: он перестаёт быть зависимостью `FilesWorkspace` и остаётся доступным для возможного повторного использования.

## Проверка

Компонентный тест подтверждает, что при наличии разных заданий обе карточки отображаются, а поисковое поле, список статусов и поясняющая строка отсутствуют.
