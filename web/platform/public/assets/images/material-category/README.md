# Nature category reference media

50 already cached public image previews from the user-approved Magnific reference
15, `https://www.magnific.com/photos/nature`. Source files, URLs, dimensions and
SHA-256 hashes: `docs/research/material-category-reference-media.json` at repo root.

Previews are normalized lossless WebP; decoded pixel equality is checked. Dominant
color is measured from the pixels; orientation uses actual preview dimensions.
AI labels come only from explicit source badges/text. Missing license or people
metadata is kept unspecified, not interpreted as a commercial license or no people.

Prompts are new editorial suggestions, not original source prompts. These images
support a local draft/noindex reference reconstruction. Replace them with owned or
licensed material before an indexed launch. No trackers, original JS or private data.
