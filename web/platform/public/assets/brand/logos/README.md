# Epifera vector identity

`epifera-logo.svg` is the original SVG supplied by the project owner, preserved
without modification. It contains the gradient mark, outlined lettering and i
dot; it has no background, embedded font, script or external resource.

Responsive UI uses the same paths in `../marks/epifera-mark.svg` and
`../wordmarks/epifera.svg`, selected through `branding/brand.json`. Cropping and
positioning change only view boxes/transforms. The lettering inherits theme
color; mark and dot keep the supplied gradients. The 32px/48px browser icons
and 180px device icon are rendered from the mark SVG.
