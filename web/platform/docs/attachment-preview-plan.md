# Просмотр прикреплённых фото

Статус: реализовано и проверено 2026-09-17.

Цель: открывать фото из поля ввода и отправленного сообщения в существующем
`MediaPreviewDialogTemplate`, без правой панели. Использовать текущие URL вложений,
не создавать отдельный просмотрщик и не менять серверный контракт.

- [x] Сделать `infoPanel` необязательным; без него отдать место изображению на
  широком и узком экране. Сохранить текущий режим файлов и примеров.
- [x] Добавить тонкую специализацию `AttachmentPreviewDialog` для `{id, src, alt}`:
  общий каркас, оригинальные пропорции, стрелки/миниатюры при нескольких фото,
  Escape, крестик, возврат фокуса.
- [x] Подключить готовые превью `ChatComposer` и загруженные изображения
  `ConversationInputImages`. Повтор/удаление — отдельные кнопки. Blob URL живёт
  до удаления вложения/размонтирования владельца; запросы остаются через API.
- [x] Проверить поведение модульными тестами и в локальном симуляторе при
  ширинах 1280 и 390: выбор второго фото, навигация, закрытие, сохранение черновика,
  просмотр после отправки, отсутствие информационной панели и обрезки.
- [x] Обновить UI-каталог и инструкции проверки; выполнить typecheck и точечный lint.

Проверки: 108 модульных тестов компонентов (включая существующие файлы и примеры), 2 браузерных сценария Playwright,
`npm run typecheck` и ESLint изменённых TS/TSX-файлов — успешно.

Ограничения: без новых зависимостей, без изменения auth/billing/jobs. Только
проверенные существующим транспортом изображения; содержимое не становится HTML.
