# Фирменная страница 404

Дизайн согласован 19 сентября 2026: пользовательский персонаж на прозрачном фоне,
крупные приглушённые цифры 404, ровный фон без свечения, заголовок «Страница не найдена»
без пояснения и прозрачная кнопка «На главную». Композиция по центру без
карточки, лёгкое покачивание с отключением при reduced motion. Уточнение пользователя:
все неизвестные адреса страниц показывают композицию справа с рабочим меню платформы.

Catch-all использует существующую проверку сессии и logout boundary. При недоступной
сессии 404 доступна в гостевой оболочке; обычная страница кабинета по-прежнему
проверяет сессию. Корневой fallback не читает аккаунт. Авторизация, API, обработка
неизвестных языков и технических путей сохраняются. Без новых зависимостей,
коммита, пуша и деплоя.
