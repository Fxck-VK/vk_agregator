# Общие состояния интерфейса

Согласованный объём: связать активные места из аудита 18 сентября с общим оформлением, затем проверять их с пользователем по порядку. Только frontend; запросы, права, биллинг, повторы платных действий и idempotency остаются у существующих контроллеров.

## Контракт

- `LoadingIndicator`: существующий круг загрузки вложений, вынесенный в общий компонент; известный прогресс и неопределённое ожидание, доступное имя, reduced motion.
- `Skeleton` / `SkeletonGrid`: общая заливка и движение; размеры задаёт потребитель, сетка фото использует MasonryGrid.
- `StateNotice`: текстовое ожидание, ошибка, пустой список или результат действия. Смысловые сообщения сохраняются; поверхности, отступы и выравнивание общие.
- `RetryAction`: общий RetryUploadIcon и прозрачный Button. Доступное имя, подсказка, disabled; никаких собственных сетевых запросов.
- `MediaState` / `MediaImage`: общий центрированный индикатор/повтор, отдельно от получения JSON. Повтор загружает тот же разрешённый URL; blob URL принадлежит владельцу. Интерактивные кнопки не вкладываются друг в друга.
- Общие CSS variables для фона, обводки, скруглений и времени движения; размеры остаются у карточки/миниатюры/просмотрщика.
