# PopoverPanel

Общая оболочка панели, которая открывается возле кнопки. Используется в `ImageAspectRatioSelector`, `ImageQualitySelector` и `ChatMediaMenu`.

Компонент задаёт тонировку, рамку, тень, скругление 0.5rem и прокрутку через `ScrollArea`. Размещает панель под кнопкой, а если снизу места недостаточно — над ней или в пределах экрана. При прокрутке и изменении окна обновляет положение. Закрывает панель по Escape с возвратом фокуса на кнопку и по нажатию снаружи без перехвата фокуса.

```tsx
const [isOpen, setIsOpen] = useState(false);
const triggerRef = useRef<HTMLButtonElement>(null);

<>
  <InputControlChip
    aria-expanded={isOpen}
    aria-haspopup="dialog"
    onClick={() => setIsOpen((open) => !open)}
    ref={triggerRef}
  >
    Настройки
  </InputControlChip>
  <PopoverPanel
    align="end"
    anchorRef={triggerRef}
    isOpen={isOpen}
    label="Настройки"
    onClose={() => setIsOpen(false)}
    width={352}
  >
    <button onClick={() => {
      setIsOpen(false);
      triggerRef.current?.focus();
    }} type="button">
      Применить
    </button>
  </PopoverPanel>
</>
```

| Параметр | Назначение |
| --- | --- |
| `anchorRef` | Ссылка на кнопку, относительно которой размещается панель. |
| `isOpen` | Управляемое состояние открытия. |
| `onClose` | Запрос закрытия по Escape или нажатию снаружи. |
| `label` | Доступное название панели. |
| `role` | `dialog` (по умолчанию) или `menu` для списка действий. |
| `itemVariant` | `selection` (по умолчанию) — обводка при наведении; `action` — обводка и подсветка текста и иконки. |
| `id` | Необязательный идентификатор панели для `aria-controls` кнопки. |
| `width` | Желаемая ширина в пикселях; уменьшается на узком экране. |
| `align` | `start` (по умолчанию) — по левому краю кнопки; `end` — по правому. |
| `portalLayer` | Необязательный z-index портальной панели; по умолчанию 50. В редакторе фото используется 170, поверх ModalBackdrop (160). Оба селектора формата/разрешения передают параметр в PopoverPanel. |
| `children` | Заголовок и содержимое; выбор значения и оформление вариантов принадлежат селектору. |

Панель немодальная: фон не блокируется. Внешняя кнопка управляет открытием, а селектор закрывает панель после выбора значения. Общее оформление меняется в `PopoverPanel.module.css`, цвета и тень — через токены `--panel-surface-*`.

При открытии фокус получает выбранный radio или первый доступный элемент. Tab и Shift+Tab за пределы списка закрывают панель и возвращают фокус к кнопке. События Tab и стрелок внутри панели не уходят во внешний просмотрщик, чтобы он не перехватывал фокус и не переключал фотографии. Переход между вариантами стрелками по-прежнему задаёт потребитель.

## Кнопки выбора

Для вариантов внутри панели используется `PopoverOption` из `@/components/ui/PopoverOption/PopoverOption`. У него прозрачный фон, скругление `0.5rem` и фиолетовая рамка при выборе, наведении и фокусе с клавиатуры.

Поведение пунктов задаётся параметром `itemVariant` у `PopoverPanel` или `PopoverSurface`:

- `selection` — выбранный вариант белый с постоянной обводкой; остальные приглушённые, при наведении и фокусе появляется только обводка. Используется для разрешения и соотношения сторон.
- `action` — при наведении и фокусе текст и иконка становятся белыми вместе с появлением обводки. Используется в `ChatMediaMenu`: `<PopoverPanel itemVariant="action" ...>`. Кнопки и ссылки действий используют общий класс `control`, иконки наследуют цвет через `currentColor`.

В обоих вариантах фон пунктов остаётся прозрачным. `itemVariant` управляет только оформлением; роли и обработчики действий задаются содержимым панели.

Если в одной панели есть действия и переключатель выбора, общий класс `actionItems` из `selectable-control.module.css` назначается только группам действий. Так устроено меню аккаунта: «Профиль», «Поддержка», «Что нового?» и «Выйти» подсвечиваются целиком, а переключатель темы использует поведение выбора.

Общие визуальные состояния `PopoverOption` и `ModeSwitchPanel` задаёт класс `control` в `src/components/ui/selectable-control.module.css`. Он определяет выбор по `aria-checked`, `aria-pressed` или `aria-selected`. Размеры и расположение содержимого задаются в компонентах. `ModeSwitchPanel` устанавливает `--selectable-active-border-color: transparent`, поскольку выбранную кнопку уже обводит его движущийся индикатор.

```tsx
<div role="radiogroup" aria-label="Разрешение">
  {options.map((quality) => (
    <PopoverOption
      key={quality}
      selected={quality === value}
      onClick={() => {
        onChange(quality);
        setIsOpen(false);
        triggerRef.current?.focus();
      }}
    >
      {quality}
    </PopoverOption>
  ))}
</div>
```

`selected` управляет состоянием `aria-checked`; компонент использует роль `radio` и по умолчанию `type="button"`. Остальные стандартные свойства кнопки, включая `disabled`, обработчики и `ref`, передаются напрямую.
